# miniscreen

Command-line driver for the WeAct Studio **Display FS 0.96 Inch** USB screen (160x80 IPS, USB CDC serial, VID `1A86` / PID `FE0C`): live system dashboard, images, animated GIFs and text.

| Folder | System | Dashboard |
|---|---|---|
| [windows](windows) | Windows | Clock + CPU / RAM / GPU |
| [freebsd](freebsd) | FreeBSD | CPU / RAM / temperature / network, rc.d service |

Both versions share the same commands. Ready-made binaries are on the [Releases](https://github.com/k-vanier/miniscreen/releases/latest) page.
